## Everything else

The ocean and singing-bowl soundscapes, the phase chime and the closing bowl are
synthesised at runtime with the Web Audio API — as is a stand-in rain, used when the
recorded one cannot be loaded. There are no other audio assets, and no third-party code
of any kind: the app has no dependencies.
